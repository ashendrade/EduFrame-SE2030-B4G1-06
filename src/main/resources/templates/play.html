In the MVC design, is it standard practice to write input validation in the Model or should it be evaluated by the Controller before parsing?

KJ

Great question, Ashendra. Input formatting validation (e.g. correct email pattern) is usually handled in the Controller/DTO mapping. Domain validation (e.g. check if email already exists in Database) belongs to the Model/Service layer.
